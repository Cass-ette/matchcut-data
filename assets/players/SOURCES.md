# 选手照片来源

图片来自 [Riot LoL Esports](https://lolesports.com/)、[LPL 赛事官网](https://lpl.qq.com/) 与 [ProSettings](https://prosettings.net/players/) 的公开资料，保留透明背景，保存为本地 PNG。获取日期：2026-10-09。LoL 图片等比缩到最长边不超过 900 像素，不放大低清原图。

每张图的资料页、原图地址、选手名、游戏与选手 ID 都记录在 [Matchcut Data 选手目录](https://github.com/Cass-ette/matchcut-data/blob/main/catalog/player-photos.json)。当前包含 CS 示例 OG / Monte 的十名选手及 163 名 LoL 选手。164 份 LoL 档案中，GAM 的 tiphat 仅有官方占位剪影，已排除并标记缺图。

LoL 身份档案和跨来源核对依据在 `catalog/lol-players.json`；2026 德杯与 S 赛名单在 `catalog/lol-events.json`，只引用个人 ID。官网阵容或比赛出场记录只是身份核对证据，不是照片绑定键。德杯依据 DCGI 已出场名单；S 赛依据 Riot 公布的 19 支参赛队及其赛前最近出场阵容，不能视为已核实的最终报名表。另有 9 名选手的官网身份与本赛季出场记录得到核实，但不宣称他们已报名本届赛事。

照片是资料页获取时的形象，不宣称队服对应历史比赛日期。人物照片的版权属于各自摄影者、战队或发布方，素材不包含在项目代码许可的授权范围内。

共享默认照片由 Matchcut Data 维护；应用内新选手也可通过素材管理预览和绑定，避免仅凭同名自动配错。
