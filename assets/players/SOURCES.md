# 选手照片来源

图片来自 [ProSettings](https://prosettings.net/players/) 的公开选手资料页，保留透明背景，转换为本地 PNG。获取日期：2026-10-09。

每张图的资料页、原图地址、选手名、游戏与选手 ID 都记录在 [Matchcut Data 选手目录](https://github.com/Cass-ette/matchcut-data/blob/main/catalog/player-photos.json)。当前包含 CS 示例 OG / Monte 的十名选手及 LoL 示例 T1 的五名选手。

照片是资料页获取时的形象，不宣称队服对应历史比赛日期。人物照片的版权属于各自摄影者、战队或发布方，素材不包含在项目代码许可的授权范围内。

共享默认照片由 Matchcut Data 维护；应用内新选手也可通过素材管理预览和绑定，避免仅凭同名自动配错。
