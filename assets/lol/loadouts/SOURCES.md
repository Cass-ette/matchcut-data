# LoL 召唤师技能与符文

Riot Games 游戏美术与名称。内置 14.6、16.18 两个符文目录，共 173 张本地技能、符文与属性碎片图标。

- 符文目录：Riot Data Dragon 对应版本的 `data/zh_CN/runesReforged.json`。
- 符文和碎片图片：`https://ddragon.leagueoflegends.com/cdn/img/perk-images/`，使用目录提供的路径。
- 属性碎片名称及图片路径：CommunityDragon 对应版本的 `plugins/rcp-be-lol-game-data/global/zh_cn/v1/perks.json`。
- 召唤师技能：Riot Data Dragon 16.18.1 的 `summoner.json` 及 `img/spell/`；两个目录使用同一套九种峡谷技能图标。

每个目录保存版本、来源 URL 和获取时间；SHA256 由 matchcut-data manifest.json 记录。技能目录只供手动选择，不表示某个选手实际带了该技能。比赛符文只来自经过选手、英雄、位置、阵营、时间和补丁核对的官方开局记录；不将单局配置复制为系列赛配置。
